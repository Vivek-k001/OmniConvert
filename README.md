## ⚡ Overview
**OmniConvert** is an all-in-one web utility suite that executes all media and document transformations **100% inside your browser**. 

No files are ever uploaded to any cloud server, ensuring complete confidentiality, zero latency, offline capability, and infinite scalability.

---

## 🛠️ Feature Modules

### 1. 🖼️ Image to PDF & PDF Merger
- Drag-and-drop multiple images (PNG, JPG, WebP, GIF).
- Reorder pages with interactive drag-and-drop sorting.
- Rotate pages on-the-fly.
- Customize page margins (Full bleed, 10mm, 20mm), orientation (Auto, Portrait, Landscape), and sizes (A4, Letter, Original Image Size).

### 2. 📉 Client-Side Image Optimizer & Converter
- Optimize image payloads on the fly without quality loss.
- Convert formats between **WebP, JPEG, and PNG**.
- Real-time file compression percentage and savings calculation.
- Optional dimension cap downscaling (2K, Full HD, HD, Blog).

### 3. 🎨 Vector & SVG Rasterizer
- Convert SVG vector artwork into raster formats (PNG with alpha transparency, WebP, JPEG).
- Scale multipliers (1x, 2x Retina, 4x Ultra HD, 8x Print Ready) or custom pixel dimensions.
- Live SVG code paste & render viewer.

### 4. 📝 Document & Markdown to PDF
- Markdown and text editor with instant synchronized preview.
- Theme switching (Clean White, Dark Modern, Warm Sepia).
- Client-side PDF formatting and direct HTML export.

---

## 🔒 Privacy & Architecture
- **HTML5 Canvas & Web APIs**: Fast pixel manipulations in memory.
- **Pure JavaScript Libraries**: `jsPDF`, `SortableJS`, `marked.js`, `html2pdf.js`.
- **Zero Remote Dependencies / Telemetry**: Runs disconnected from network once loaded.
